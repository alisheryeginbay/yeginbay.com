Since I consider this website my personal notebook, I try to minimize the usage of AI. I don't have any interest in pretending that tokens produced by LLM are my words and my thinking; I believe writing[^1] *is* thinking, hence I think there's no benefit of delegating the actual thinking process to AI.

But AI is still very helpful and I frequently use it while building this website. Almost every line of code on this website's infrastructure ([source](https://github.com/alisheryeginbay/yeginbay.com)) is written using Claude. It also maintains the [test page](/test).

For transparency, I mention any usage of AI. For example, [test page](/test) includes Claude Opus 5.5 (as of 14 October 2026) as one of the authors. I also keep Claude Code's [git attribution](https://code.claude.com/docs/en/settings-reference#git-and-attribution) enabled, so that it is clear which [commits](https://github.com/alisheryeginbay/yeginbay.com/commits/main/) are co-authored by Claude or any other AI.

[^1]: Using my own biological neurons!
